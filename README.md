# 📂 File Handling System – Python Project

A simple Python-based application that demonstrates file handling operations such as writing, reading, and appending data to a text file. This project helps beginners understand how data can be stored and managed using files.

---

## 📌 About The Project

This project is designed to introduce fundamental file operations in Python. It allows users to create a file, write data into it, append additional data, and read the stored content.

It showcases important programming concepts such as:

* File handling (`read`, `write`, `append`)
* Exception handling
* User input handling
* Functions for modular programming

The system simulates a basic data storage mechanism where user input is saved and retrieved from a file.

---

## 🎯 Key Functionalities

* Writes user input to a file
* Appends additional data without overwriting existing content
* Reads and displays file content
* Handles errors if file is not found

---

## 🚀 Features

* Simple and interactive command-line interface
* Uses text file (`data.txt`) for storage
* Demonstrates all basic file modes (`w`, `r`, `a`)
* Beginner-friendly implementation
* Lightweight and easy to understand

---

## 🛠️ Technologies Used

* Python 3
* Built-in file handling system

---

## ▶️ How to Run the Program

1. Ensure Python is installed on your system
2. Save the file as `file_handling.py`
3. Open terminal or command prompt
4. Run the program using:

```bash id="f12a9x"
python file_handling.py
```

---

## 📂 How It Works

1. The program first asks the user to enter data and writes it to a file (`data.txt`)
2. Then it allows the user to append additional data
3. Finally, it reads and displays the entire content of the file
